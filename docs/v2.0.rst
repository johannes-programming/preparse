Overview
--------

The ``preparse`` project allows to preparse arguments before the main parsing.

Installation
------------

To install ``preparse``, you can use ``pip``.
Open your terminal and run:

.. code-block:: shell

    pip install preparse

Typing
------

The typing conforms strictly to ``mypy``.

.. container:: versionchanged

    **Changed in version 2.0.**

Introduction
------------

The ``preparse`` project allows for preprocessing a ``list`` of arguments
so that they can be parsed definitively in a later step.
This way, the functionality of another parsing system can be modified.
The project is inspired by the ``getopt`` and ``getopt_long`` libraries within ``C``.
Version 2.0 exposes a standalone preparser; integration with a downstream parser
is performed by passing the resulting arguments to that parser.

The following example expands an abbreviated long option and attaches
a required argument to its option:

.. code-block:: python

    from preparse import PreParser

    parser = PreParser(
        optDict={
            "-v": PreParser.OptDict.Nargs.NO_ARGUMENT,
            "--verbose": PreParser.OptDict.Nargs.NO_ARGUMENT,
            "--output": PreParser.OptDict.Nargs.REQUIRED_ARGUMENT,
        }
    )
    parser.transformation.abbr = PreParser.Transformation.Tuning.MAXIMIZE
    parser.transformation.equal = PreParser.Transformation.Tuning.MAXIMIZE

    args, messages = parser.parse_args(["--verb", "--output", "result.txt"])
    # args == ["--verbose", "--output=result.txt"]
    # messages == []

    for message in messages:
        print(message.oneliner())

The ``parse_args`` method returns both the transformed argument ``list``
and a ``list`` of structured diagnostic messages.
The caller decides how to present or handle these messages.

Features
--------

``preparse.PreParser``
~~~~~~~~~~~~~~~~~~~~~~

``class preparse.PreParser(other=None, /, *, framework=None, optDict=None, transformation=None)``
^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^

This ``class`` is the centerpiece of ``preparse``.
Its behaviour follows the principles of ``getopt`` from ``C``.
It is intended for argument parsers compatible with traditional ``getopt`` logic.
The optional ``other`` argument copies the configuration of another ``PreParser``.
The remaining keyword arguments set the three configuration objects.

``copy() -> Self``
""""""""""""""""""

This method returns a copy of the current instance,
with independently mutable configuration objects.

``framework: preparse.PreParser.Framework``
"""""""""""""""""""""""""""""""""""""""""""

This ``property`` holds the rules used to recognize options.
Its fields can be modified in place. Assigning another ``Framework`` updates
the existing object rather than replacing it.

``optDict: preparse.PreParser.OptDict``
"""""""""""""""""""""""""""""""""""""""

This ``property`` holds the definitions of accepted options.
The keys are option spellings and the values describe how many arguments
the option takes. Assigning a mapping or an iterable of key-value pairs
replaces the dictionary contents.

``parse_args(args: Iterable[str] | None = None) -> tuple[list[str], list[preparse.Message]]``
"""""""""""""""""""""""""""""""""""""""""""""""""""""""""""""""""""""""""""""""""""""""""""""

This method is at the core of the ``class``.
It returns a ``tuple`` containing the preparsed argument ``list`` and a ``list``
of diagnostic message objects. If ``None`` is passed as ``args``,
then ``sys.argv[1:]`` is used. Diagnostics describe the supplied input,
even when the corresponding option is modified or dropped.
The transformation is designed to reach a stable result, so preparsing
the resulting argument ``list`` again does not change it.

``transformation: preparse.PreParser.Transformation``
"""""""""""""""""""""""""""""""""""""""""""""""""""""

This ``property`` holds the transformations applied after options
have been recognized. Its fields can be modified in place.
Assigning another ``Transformation`` updates the existing object.

``preparse.PreParser.Framework``
~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~

``class preparse.PreParser.Framework(other=None, /, *, allows_long=None, allows_short=None, is_posix=None)``
^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^

This ``class`` controls the conventions under which options are recognized.
The optional ``other`` argument copies another ``Framework``.
A keyword argument of ``None`` leaves the corresponding field unchanged.

``allows_long: bool``
"""""""""""""""""""""

This boolean field determines whether long options are recognized.
The default is ``True``. When only long options are allowed,
single-dash long-option spellings are also supported.

``allows_short: bool``
""""""""""""""""""""""

This boolean field determines whether short options are recognized.
The default is ``True``.

``copy() -> Self``
""""""""""""""""""

This method returns a copy of the current ``Framework``.

``is_posix: bool``
""""""""""""""""""

This boolean field selects POSIX option ordering.
If ``True``, option recognition stops at the first positional argument.
If ``False``, options and positional arguments may be interleaved.
The default is ``False``.

``update(other: preparse.PreParser.Framework | None) -> None``
""""""""""""""""""""""""""""""""""""""""""""""""""""""""""""""

This method copies the non-``None`` fields of another ``Framework``
into the current instance. Passing ``None`` leaves it unchanged.

``update_fields(*, allows_long=None, allows_short=None, is_posix=None) -> None``
""""""""""""""""""""""""""""""""""""""""""""""""""""""""""""""""""""""""""""""""

This method updates individual fields.
For each field, ``None`` means that no change is made.

``preparse.PreParser.OptDict``
~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~

``class preparse.PreParser.OptDict(other=None, /, **kwargs)``
^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^

This ``class`` is a subclass of ``dict[str, preparse.PreParser.OptDict.Nargs]``.
It normalizes option keys to ``str`` and values to the ``Nargs`` enum.
The constructor accepts an object with ``keys`` and ``__getitem__``,
an iterable of key-value pairs, and keyword arguments.
The usual dictionary operations are available, including ``copy``,
``get``, ``pop``, ``update``, and the union operators.

Option names normally have the form ``-x`` for a short option
or ``--name`` for a long option. The ``Framework`` settings determine
which dictionary entries are considered valid options.
Options absent from the dictionary produce diagnostic messages.

``copy() -> Self``
""""""""""""""""""

This method returns a copy of the current dictionary.

``fromkeys(keys: Iterable[object], value: object = None, /) -> Self``
"""""""""""""""""""""""""""""""""""""""""""""""""""""""""""""""""""""

This ``classmethod`` creates a dictionary with the supplied keys
and argument-count value. If ``value`` is ``None``, it returns an empty dictionary.

``update(other=None, /, **kwargs) -> None``
"""""""""""""""""""""""""""""""""""""""""""

This method adds or replaces entries from a mapping, an iterable
of pairs, or keyword arguments. Keys and values are normalized.

``class preparse.PreParser.OptDict.Nargs``
^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^

This ``enum.IntEnum`` class describes the argument count of an option.

+-----------------------+-------+---------------------------------------+
| Name                  | Value | Explanation                           |
+=======================+=======+=======================================+
| ``NO_ARGUMENT``       | ``0`` | The option does not take an argument. |
+-----------------------+-------+---------------------------------------+
| ``REQUIRED_ARGUMENT`` | ``1`` | The option requires an argument.      |
+-----------------------+-------+---------------------------------------+
| ``OPTIONAL_ARGUMENT`` | ``2`` | The option may take an argument.      |
+-----------------------+-------+---------------------------------------+

When converting values to ``Nargs``, ``None`` becomes ``NO_ARGUMENT``;
values other than ``0`` and ``1`` become ``OPTIONAL_ARGUMENT``.
Direct assignment of ``None`` to an ``OptDict`` entry is ignored.

``preparse.PreParser.Transformation``
~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~

``class preparse.PreParser.Transformation(other=None, /, *, abbr=None, bundling=None, depletion=None, equal=None, order_compatibility=None)``
^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^

This ``class`` configures how recognized arguments are transformed.
The optional ``other`` argument copies another ``Transformation``.
The fields use ``Tuning`` for three-way behaviour, except for ``depletion``.

``abbr: preparse.PreParser.Transformation.Tuning``
""""""""""""""""""""""""""""""""""""""""""""""""""

This field determines whether recognized long-option abbreviations
are minimized, expanded to their full spelling, or maintained.
The default is ``Tuning.MINIMIZE``. An exact option name takes precedence
over an abbreviation, and ambiguous or invalid options are not rewritten.

``bundling: preparse.PreParser.Transformation.Tuning``
""""""""""""""""""""""""""""""""""""""""""""""""""""""

This field determines whether short options are separated,
bundled together when possible, or maintained in their current bundles.
The default is ``Tuning.MAINTAIN``. A short option taking an argument
limits which options may share its bundle.

``copy() -> Self``
""""""""""""""""""

This method returns a copy of the current ``Transformation``.

``depletion: preparse.PreParser.Transformation.Depletion | str``
""""""""""""""""""""""""""""""""""""""""""""""""""""""""""""""""

This field determines the handling of a recognized option whose
required argument is missing. ``Depletion.DROP_OPT`` removes that option;
``Depletion.DEFER`` keeps it without a value.
A ``str`` instead supplies that string as the missing argument.
The default is ``Depletion.DROP_OPT``.

``equal: preparse.PreParser.Transformation.Tuning``
"""""""""""""""""""""""""""""""""""""""""""""""""""

This field determines whether required arguments of long options
are separated from the option, joined with ``=``, or maintained in their
existing form. The default is ``Tuning.MAINTAIN``.
Optional arguments of long options are only taken when attached with ``=``.

``order_compatibility: preparse.PreParser.Transformation.Tuning``
"""""""""""""""""""""""""""""""""""""""""""""""""""""""""""""""""

This field determines whether to minimize, maximize, or maintain
compatibility between POSIX option ordering and interleaved option ordering.
The default is ``Tuning.MAXIMIZE``. Maximization may reorder options
and positional arguments or insert ``--`` to preserve their interpretation.

``update(other: preparse.PreParser.Transformation | None = None, /) -> None``
"""""""""""""""""""""""""""""""""""""""""""""""""""""""""""""""""""""""""""""

This method copies the fields of another ``Transformation``
into the current instance. Passing ``None`` leaves it unchanged.

``update_fields(*, abbr=None, bundling=None, depletion=None, equal=None, order_compatibility=None) -> None``
""""""""""""""""""""""""""""""""""""""""""""""""""""""""""""""""""""""""""""""""""""""""""""""""""""""""""""

This method updates individual fields.
For each field, ``None`` means that no change is made.

``class preparse.PreParser.Transformation.Tuning``
^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^

This ``enum.IntEnum`` class determines the goal of a transformation.
A transformation may be constrained when the requested change would alter
the recognized meaning of an argument.

+--------------+-------+-------------------------------------------------+
| Name         | Value | Explanation                                     |
+==============+=======+=================================================+
| ``MINIMIZE`` | ``0`` | The PreParser minimizes the aspect in question. |
+--------------+-------+-------------------------------------------------+
| ``MAXIMIZE`` | ``1`` | The PreParser maximizes the aspect in question. |
+--------------+-------+-------------------------------------------------+
| ``MAINTAIN`` | ``2`` | The PreParser does not make unforced changes.   |
+--------------+-------+-------------------------------------------------+

When converting values to ``Tuning``, ``None`` becomes ``MINIMIZE``;
values other than ``0`` and ``1`` become ``MAINTAIN``.

``class preparse.PreParser.Transformation.Depletion``
^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^

This ``enum.Enum`` class determines what happens to an option
whose required argument cannot be found.

+--------------+----------------+----------------------------------------+
| Name         | Value          | Explanation                            |
+==============+================+========================================+
| ``DROP_OPT`` | ``"DROP_OPT"`` | Discard the option.                    |
+--------------+----------------+----------------------------------------+
| ``DEFER``    | ``"DEFER"``    | Retain the option without an argument. |
+--------------+----------------+----------------------------------------+

``preparse.Message``
~~~~~~~~~~~~~~~~~~~~

``class preparse.Message``
^^^^^^^^^^^^^^^^^^^^^^^^^^

This abstract base ``class`` is the base for the preparsing diagnostics.
Messages are returned by ``PreParser.parse_args`` rather than being emitted
as Python warnings.

``oneliner() -> str``
"""""""""""""""""""""

This abstract method returns a one-line, ``getopt``-style
description of the diagnostic.

``preparse`` message classes
~~~~~~~~~~~~~~~~~~~~~~~~~~~~

The following ``dataclass`` types implement ``Message``.
Their fields carry the diagnostic details; ``oneliner`` formats the details
as a human-readable string.

``class preparse.AmbiguousOptionMessage(option: str, possibilities: list[str])``
^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^

This ``class`` reports an ambiguous abbreviation of a long option.
Its ``option`` field contains the supplied spelling and ``possibilities``
lists the matching long options.

``class preparse.InvalidOptionMessage(option: str, is_long: bool)``
^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^

This ``class`` reports an unrecognized long option or an invalid
short option. The ``is_long`` field distinguishes the two cases.

``class preparse.RequiredArgumentMessage(option: str, is_long: bool)``
^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^

This ``class`` reports a recognized option whose required argument
is missing. The ``is_long`` field distinguishes long and short options.

``class preparse.UnallowedArgumentMessage(option: str)``
^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^

This ``class`` reports a long option that does not allow an argument
but was supplied with a value using ``=``.

``preparse.SupportsKeysAndGetitem``
~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~

``class preparse.SupportsKeysAndGetitem[Key, Value]``
^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^

This runtime-checkable ``typing.Protocol`` is used to annotate
mapping-like inputs to ``OptDict``. It requires the following methods:

``__getitem__(key: Key, /) -> Value``
"""""""""""""""""""""""""""""""""""""

This method retrieves the value corresponding to a key.

``keys() -> Iterable[Key]``
"""""""""""""""""""""""""""

This method returns the keys of the mapping-like object.
